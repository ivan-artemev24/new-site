# Квиз: Безопасность в сети

Интерактивный веб-квиз по теме кибербезопасности, созданный как одностраничное приложение с современным адаптивным дизайном.

## 🌐 Демо

Проект готов к развертыванию на GitHub Pages. Для просмотра просто откройте файл `index.html` в браузере.

## ✨ Особенности

### 🎨 Дизайн
- **Современный адаптивный дизайн** – отлично выглядит на мобильных устройствах и ПК
- **Светлая цветовая гамма** – приятная для глаз палитра с градиентами
- **Плавные анимации** – переходы между экранами, эффекты при наведении, анимации ответов
- **Интерактивные элементы** – кнопки с ripple-эффектом, hover-анимации

### 📱 Функциональность
1. **Стартовый экран** – приветствие и описание квиза
2. **8 вопросов по безопасности** – охватывают основные темы кибербезопасности
3. **Интерактивные варианты ответов** – с визуальной обратной связью
4. **Индикатор прогресса** – показывает текущий вопрос и общее количество
5. **Система подсчета баллов** – автоматический расчет результатов
6. **Финальный экран с результатами** – персонализированная оценка знаний
7. **QR-код** – быстрый доступ к связанному сайту
8. **Кнопка "Поделиться"** – возможность поделиться результатами

### 🛡️ Темы вопросов
1. **Фишинг (Phishing)** – что это и как защититься
2. **Надежные пароли** – критерии безопасности
3. **Двухфакторная аутентификация (2FA)** – назначение и важность
4. **Безопасное соединение (HTTPS)** – значение знака "замочка"
5. **Социальная инженерия** – методы и защита
6. **Безопасность электронной почты** – как реагировать на подозрительные письма
7. **Вымогательское ПО (Ransomware)** – что это и последствия
8. **Публичные Wi-Fi сети** – риски и меры предосторожности

## 🚀 Развертывание на GitHub Pages

1. Создайте репозиторий на GitHub
2. Загрузите файлы в репозиторий:
   - `index.html`
   - `README.md`
3. В настройках репозитория перейдите в раздел "Pages"
4. Выберите ветку `main` и папку `/ (root)`
5. Сохраните изменения – сайт будет доступен по адресу:
   ```
   https://[ваше-имя-пользователя].github.io/[название-репозитория]/
   ```
